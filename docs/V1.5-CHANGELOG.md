# Scoutline Version 1.5

Version 1.5 completes the match-day loop: create a match, capture observations, finish or defer the closing assessment, and export a reliable record for onward reporting.

## Deliverables

- `dist/` — production-ready static PWA build.
- Structured match export (`.json`) — the versioned machine-readable source record.
- AI handoff report (`.md`) — the consistent human-readable and AI-ready bridge to later report formats.
- Match backup (`.json`) — the unchanged full browser-state safety copy.

The structured export and handoff are generated independently from the saved state and do not alter the live match or backup.

## Preserved Version 1.4 behaviour

The hold-to-toggle clock, explicit clock states, visible and locked observation save, improved dictation feedback, Run and Skill actions, mobile zoom safeguards, Finish Later workflow, early termination, and safe report resumption remain in place. Early termination now also uses the same non-duplicating Finish Later pattern as full-time.

## Deployment

1. From the project folder, run `npm test`.
2. Run `npm run build`.
3. Push the tested project to the existing Git repository.
4. In Vercel, import or open that repository and use `npm run build` as the build command and `dist` as the output directory.
5. Deploy, then open the production URL once online so the Version 1.5 service worker installs and replaces the Version 1.4 cache.
6. Complete a short acceptance check: open an existing or test match, reach the summary screen, download both V1.5 files, verify the JSON opens, and verify the Markdown contains the fixture, chronological timeline, individual-player sections, closing assessment, and data-quality notes.

No backend or environment variables are required. Match data remains local to the browser profile until the scout downloads it. Clearing site data can remove the local match, so retain the downloaded backup before clearing browser storage.

## Deferred refinements

Captain marker readability, disciplinary and sent-off handling, Quick Note/Other actions, and in-app photo/screenshot/online line-up acquisition remain deliberately outside this build. They should be reviewed after V1.5 is deployed and before the next real-world test.
