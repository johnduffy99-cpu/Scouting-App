# Scoutline Version 1.7 field-test release

Version 1.7 preserves the complete Version 1.6 match workflow and adds detailed goalkeeper capture, solid-colour player icons and staged two-team placement.

## Deployment configuration

The Vercel project requires:

- `OPENAI_API_KEY` — server-side OpenAI Platform API key.
- `SCOUTLINE_ALLOWED_ORIGIN` — exact permanent production address without a trailing slash.

Optional:

- `OPENAI_LINEUP_MODEL` — defaults to `gpt-5.6-luna`.

Keep keys out of source files, GitHub and browser settings. Retain a modest OpenAI project budget for the personal field test.

## Completed build checks

- Automated model, API and UI tests pass.
- Production static build completes successfully.
- Desktop layout tested at 1440 × 900.
- Goalkeeper save-location, shot-origin, outcome and note controls render and remain selectable.
- Team-colour confirmation and the Team 1 to Team 2 placement transition work without browser console errors.
- The Version 1.7 service-worker cache replaces previous installed builds.

## Field-test checklist

1. Open the production app online once so Version 1.7 replaces the previous offline cache.
2. Create a match with teams, competition, venue, date and kick-off.
3. Extract and review Team 1 from the real team sheet.
4. Confirm a solid icon colour and place Team 1.
5. Select **Now add Team 2** and confirm that Team 1 is hidden with an explanatory message.
6. Extract Team 2, choose a clearly different colour and place its players.
7. Confirm that both teams reappear and resolve any overlapping icons.
8. Start the match and record normal, Quick Note, disciplinary and substitution events.
9. Record goalkeeper actions using save location, shot origin, outcome and an optional dictated note.
10. Confirm a goalkeeper **Goal** outcome updates the opposing team's score.
11. Add half-time notes and complete or defer the closing report.
12. Download the Version 1.7 structured export and confirm goalkeeper fields and icon colours are present.
13. Download the AI handoff and confirm it identifies itself as Version 1.7.
14. Download and restore the safety backup in a separate test browser.
15. Use the AI handoff in a separate reporting task and check that the report follows the recorded evidence.

## Release boundary

The Version 1.7 field test is complete when the production deployment is Ready and the checklist above has been completed in a real match or controlled full-match rehearsal. Broader accounts, cloud synchronisation, configurable action banks and multi-user workflows belong to Version 2.0 planning.
